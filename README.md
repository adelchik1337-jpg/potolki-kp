# Натяжной потолок — коммерческое предложение (демо)

Демо-шаблон КП для компании «Высокий уровень» (Новороссийск) — платформа OpMax.

- Страница: https://adelchik1337-jpg.github.io/potolki-kp/
- Переключатель демо-смет вверху страницы (`#demo=lenina|pupko|gaiduk|glebovka|mefodievka|floor1|avenue`).
- Фото и видео — реальные объекты компании (с их Яндекс Диска). Блок «Наши работы» сам ставит вперёд фото с тем, что есть в смете.
- Контакты менеджера — из `KP_CONFIG.contacts` (`name, role, phone, max, telegram`): каждый менеджер заполняет свои, пустые каналы не показываются. MAX — ссылка max.ru/… или номер (тогда карточка копирует номер); WhatsApp не показывается.
- Макет для OpMax (всё инлайном, без внешних файлов) собирается тем же `build.py` в `potolki-platform.html`.

## Структура

- `index.html` — собранная страница (стили и логика внутри).
- `media/` — фото объектов (`p/`), ролик `objects.mp4` + обложка, фото команды, превью для ссылок.
- `src/` — исходники; пересборка `index.html`: `python3 src/build.py`.
