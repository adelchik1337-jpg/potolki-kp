Итого

Служебная панель — только по ссылке с #edit
  • Смета приходит из OpMax в window.KP_CONFIG = {addr, num, date, until, discount, items:[{name, unit, price, qty}], photos:[url…]}. Имена позиций — как в Excel Павла; страница сама определяет систему примыкания, свет, карнизы и строит потолок.
  • Два варианта одному клиенту: variants:[{title, note, items}] вместо items.
  • qty — число (всё в «Общая») или объект {"Общая":2.8,"Детская":3.1}.
  • Проверено на 7 сметах (8 вариантов) — сходятся с Excel до рубля, включая скидки.
  • Если платформа передала конфиг без сметы, показывается условный пример без чужих адресов, селектор демо скрыт.
  • Согласовать ничего не отправляет само: собирает сообщение с составом (что убрано/изменено) и открывает WhatsApp менеджера, либо даёт скопировать. Событие accept_click уходит в аналитику OpMax (window.__kpTrack), правки сметы — quote_toggle, выбор варианта — package_select, клики по контактам — cta_click.
  • Контакты менеджера — contacts:{name, role, phone, whatsapp, telegram, max}. Телефон/WhatsApp/Telegram — как в блоке «Контакты» OpMax; name, role и max — новые поля. Сейчас OpMax их в KP_CONFIG не передаёт — нужна доработка платформы (профиль менеджера → KP_CONFIG.contacts). Без них блок показывает только компанию, чужие контакты не подставляются. Пустые каналы не показываются; в шапке — «Позвонить» и первый заполненный мессенджер. Telegram — ник, ссылка или номер; MAX — ссылка или ник.
  • Фото и видео — из загрузок OpMax (media:[{url, kind, name}]). Объектом считается только файл, в имени которого есть тег или слово «объект»/«работа»: «теневой», «парящий», «линии», «трек», «карниз/ниша», «подсветка», «бесщелевой»… Такие фото встают перед библиотекой компании; страница ставит вперёд объекты с тем, что есть в смете, и отодвигает фото с фишками, которых в смете нет. Файл с «команда» в имени — фото команды; видео с тегом/«объект» в имени — ролик блока (в PDF печатается только с обложкой: файл «обложка»/«poster»).
